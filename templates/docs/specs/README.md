# specs

변경 단위 명세. 기능·변경 하나당 폴더 하나: `NNNN-<slug>/`

| 파일 | 내용 | 누가 |
|---|---|---|
| `spec.md` | 무엇을·왜·범위·결정 목록·수용 기준(실행 가능한 명령) | `/jig:spec` 이 쓰고 사용자가 승인 |
| `plan.md` | 작업 목록, 작업마다 먼저 쓸 테스트와 검증 명령, 의존 관계 | `/jig:spec` |
| `log.md` | 실행 기록: 작업별 증거(명령과 결과), 계획과 달라진 점 | `/jig:build` |

상태는 `spec.md` 맨 위 `status:` 한 줄로 둔다: `draft` → `approved` → `done`.
